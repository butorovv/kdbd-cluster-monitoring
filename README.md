# iu1-kbdb-2026 — Базы знаний и базы данных

Курс кафедры ИУ-1 МГТУ им. Н.Э. Баумана, 3 курс, осень 2026. Один репозиторий на весь семестр:
стек в `docker-compose.yml` растёт по ходу курса, задания добавляются папками `seminarNN/`.

## Быстрый старт

Нужны Docker (Desktop или Engine + Compose) и Git.

```bash
make up              # поднять PostgreSQL с учебным датасетом (первый запуск скачает образ)
make psql            # консоль psql
make run SEM=01      # прогнать seminar01/seminar01.sql
make setup SEM=03    # загрузить дополнительные таблицы семинара 3
make migrate         # применить миграции вашего проекта (seminar02/migrations)
make migrate-reset   # снести схему project и применить заново (только на семинаре)
make reset           # перезагрузить учебный датасет с нуля
make down            # остановить
```

Подключение из любого SQL-клиента: `localhost:5432`, база `plant`, пользователь/пароль `student` / `student`.

## Датасет (схема public)

Условная компрессорная станция: 3 площадки, 7 агрегатов, 18 датчиков, сутки телеметрии с шагом 1 минута
(2 сентября 2026), журнал событий и журнал ремонтов. Данные детерминированные и намеренно не идеальные.

| таблица | что хранит |
|---|---|
| `station` | площадка |
| `unit` | агрегат; `id` — текстовый код вида `K-2` |
| `sensor` | датчик: `kind` (temp / vibration / pressure / load), `tag`, единица измерения |
| `telemetry` | измерения: `ts`, `sensor_id`, `value` |
| `event` | события: `severity` (info / warning / alarm / unplanned_stop) — «как есть» из SCADA |
| `maintenance` | ремонты — перенесено из Excel, со всеми последствиями |
| `component` | состав агрегата: дерево узлов и деталей (семинар 3, `make setup SEM=03`) |
| `sensor_mount` | на каком узле установлен датчик (семинар 3) |
| `flow_link` | технологические связи между агрегатами; в графе есть цикл (семинар 3) |
| `unit_spec` | технические характеристики в jsonb (семинар 3) |

## Если что-то не так

- **Порт 5432 занят** — поменяйте в `docker-compose.yml` на `"5433:5432"` и подключайтесь к 5433.
- **Контейнер падает** — `make logs`.
- **Данные не загрузились** — init-скрипты выполняются только при первом создании тома: `make reset`.
- **Windows** — WSL 2 backend в Docker Desktop; репозиторий держите внутри WSL.
