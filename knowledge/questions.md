# Вопросы к базе знаний

Все фактические ответы ниже относятся к демонстрационным данным миграции `seminar02/migrations/V1__init.sql`. Значения являются синтетическими.

| ID | Вопрос | Ожидаемый ответ на демонстрационных данных | Проверка |
|---|---|---|---|
| Q01 | Какова топологическая принадлежность `a01n01`? | `SUMMIT → a01 → a01n01`; `a01` — топологическая группа, не обязательно физический шкаф. | Соединить `node` с `node_group` по родителю до корня. |
| Q02 | Сколько компонентов каждого вида у `a01n01`? | 2 CPU, 6 GPU, 2 PSU. | Группировка строк `component.kind`. |
| Q03 | Какие типы метрик и единицы поддерживаются? | PSU_INPUT_POWER (W), CPU_POWER (W), CPU_MEAN_TEMP (degC), GPU_POWER (W), GPU_CORE_TEMP (degC). | Читать `metric_type`, не выводить единицы из чисел. |
| Q04 | Какова температура GPU0 в 09:01 UTC? | 61 °C в синтетическом снимке. | Точный `ts`, компонент GPU с `local_index=0`, тип GPU_CORE_TEMP. |
| Q05 | Какие ожидаемые измерения отсутствуют в 09:01 UTC? | Температура GPU5 отсутствует; дополнительно проверяются совместимые пары компонент/тип метрики, для которых ещё не создан источник. | Компоненты × совместимые типы метрик LEFT JOIN к `metric_source`, затем к `telemetry` по точному времени. |
| Q06 | Какие события записаны для узла? | Одно демонстрационное info-событие обслуживания в 10:00 UTC. | `event` по узлу, сортировка по времени. |
| Q07 | Как обслуживали узел и какие ресурсы указаны? | Демонстрационный осмотр инженером; указано 2 салфетки. Документ — ссылка на отчёт. Схема не связывает `document` непосредственно с конкретной записью обслуживания. | `maintenance` + `engineer`; ресурсы через `maintenance_resource`; документы отдельно по `node_id`. |
| Q08 | Есть ли подтверждённый предел температуры GPU? | Нет. В обычном режиме предел неизвестен. Учебный профиль задаёт условный порог 80 °C. | Проверить применимость источника предела и явный флаг профиля. |
| Q09 | Как классифицировать температуру GPU0 в 09:01 UTC и что делать при достижении предела? | На штатном снимке 61 °C, что ниже учебного порога 80 °C. При тестовой замене значения на 80 °C срабатывает включительная граница и рекомендация сверить показание и проверить охлаждение. Это демонстрационная политика, не регламент. | Точное измерение, десятичное сравнение `>=`, повторить после изменения фикстуры, объяснение с ID правила. |
| Q10 | Почему по GPU5 нельзя заключить, что температура нормальна? | Для ожидаемого источника нет строки телеметрии в момент снимка. Рекомендация — проверить источник телеметрии. | Сохранить источник после LEFT JOIN; объяснить факт отсутствия и правило исключения. |
